# CastReader Pro 修复、发布与核查汇总

记录日期：2026-09-25，Asia/Shanghai。汇总本轮已完成的 Pro 修复及实际验证边界，供后续发布沿用。商店状态为原提交时回读；本文归档时没有重新发布应用、重新查询商店审核进度或修改用户账单。

## 最终行为

- 服务端合并同账号所有支付来源。任一渠道有有效付费权益或有效试用即可授予 Pro；某一渠道扣款失败不能覆盖另一有效来源。没有有效来源时，过期、试用转付失败及欠费均为非 Pro。取消续费但仍在有效期内保留权益。
- 官网和全球 API 共享有效期策略、身份归一与权限入口；账号查询不改设备绑定。全球扩展使用中国区 QuickRead 计算时仍查全球账号权益，国内原生账号保持国内账本。
- iOS/Android 以当前账号最近一次成功服务端 `pro` 布尔值为准，本地 StoreKit/Play 标记用于交易同步，不再 OR 覆盖服务端 false。退出或换号清理状态，旧请求不能覆盖新账号/新结果。按用户最终要求，没有新增客户端到期计时器或逐段查询；网络故障保留同账号最近成功结果。
- 扩展 1.2.46 修复 Pro 过期/撤销同步和 QuickRead 失败后的播放器占用释放；失去克隆音色权限后按解读语言回退免费默认音色继续解读，网络失败不误作权限撤销。修复阅读和账号连接流程覆盖九种语言。
- 有效 Pro 不依赖免费额度查询。既有续块恢复、查询合并及网络容错保留；本轮没有在每段 TTS 或解读续块前新增同步查库。
