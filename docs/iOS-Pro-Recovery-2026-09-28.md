# iOS Pro 恢复修复（2026-09-28）

## 问题与行为

1. 当前服务端 Pro 只保存在内存，冷启动遇到网络失败会退回默认 false。
   现在把当前账号最近成功的服务端结果存入私有 Keychain，按 canonical user id
   和线路隔离，启动先恢复再刷新。成功 false 同样持久化；退出、换账号及明确会话
   拒绝清除快照；旧请求不能污染持久化结果。缓存恢复同步更新购买待同步提示。
2. 活跃 StoreKit 交易过去在后台验单前就 finish，失败后没有主动补传。
   现在须后台确认后才 finish，同步失败保留 StoreKit 未完成交易，当前账号下按
   2/10/30 秒最多重试三次，后续前台/启动/恢复购买仍可重传。换账号取消任务；
   验单的每个异步阶段和 401 重试检查账号边界，不能借另一账号会话补传。

权限仍以服务端最近成功 true/false 为准，不回退 StoreKit OR 放行，不计算本地
到期时间，不在逐段播放中新增查询。受保护 API 继续使用当前账号 cms_ 会话。
