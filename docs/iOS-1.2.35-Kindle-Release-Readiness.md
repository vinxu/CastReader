## 本轮新增修复

复查发现 `currentItemDrained` 新状态没有处理用户回听意图：

1. 整段播完后拖回进度再点播放，播放器仍认为该段结束，无法重播。
2. 等待流式尾文时按后退，下一次播放直接进入尾文，跳过用户要求重听的前文。

两条真实 AVPlayer 测试在修改生产代码前均失败，保留 `seek-repro.xcresult` 与日志。修复通过既有的定位恢复路径重新准备当前音频段，保留暂停意图、后续队列及会话所有权；旧 AVPlayerItem 的完成回调不能影响回听。用户在定位完成前点击播放只记录意图，定位完成后才出声。新增第三条测试覆盖该立即播放操作，避免从句首短暂出声，并检查定位过程中清空队列可正确撤销等待状态。生产代码及 build56 提交为 `50b4ccc98e1e2680833313bbf509353876288611`。

发布工具的模拟数据检查增加 Kindle 设置 fixture、主题参数与辅助探针标记；保留 Debug 正控。
