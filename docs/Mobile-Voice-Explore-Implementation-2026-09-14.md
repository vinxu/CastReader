## 已实现的界面候选（专题方向待更新）

用户后续要求先研究完整社区与 Kokoro 供给，再设计类似 App Store 的专题内容流。下述两组布局是此前候选，不再作为最终产品方向。最新盘点和内容组织方案见 [音色发现研究](Voice-Discovery-Research-2026-09-14.md)；本轮只更新分析文档，未修改 UI。

- 顶部仅保留单行语言切换与最近 / 收藏 / 探索 / 我的声音导航。
- 删除顶部额度说明卡和“当前音色”说明；选中状态由列表勾选和播放器入口表达。
- 探索按“常规音色 · Pro 不限时”和“精选音色”分组。
- 精选分组标题右侧仅显示额度数字与 ⓘ；共享范围、按生成计量、免费试听与重播、更新时间放在点击后的说明中。
- 收藏和最近列表保留简短的共享月额度标记。播放器月额度音色带时钟角标。
- 音色来源语言与朗读语言独立。切换语言时，支持目标语言的精选音色保持同一个 ID；不改变文字内容。
- 音色下线、语言暂不可用、额度用尽均保留原选择与阅读位置，要求用户明确选择其他音色。

## 接入合同

- 新客户端使用 `/api/tts/mobile-catalog`。旧客户端继续使用旧目录，避免向匿名 TTS 提交公开音色 ID；新路径也绕过中国网关旧目录的静态 alias。
- 常规音色走原管线；公开精选使用 `vl_` ID，走现有受保护的 `/api/voice-clone/captioned-speech`。
- `usagePolicy=monthly_generation`、`supportedLanguages` 和各语言 `sampleUrls` 必须完整。目录缺失时，已保存的 `vl_` ID 仍走鉴权管线，不退回普通音色。
- 精选与自己的声音，所有语言都使用同一账号、同一订阅月周期的 7,200 秒额度桶。年度会员仍按月周期更新。
- 公开音色映射到运营账户预备的消费端资源；账本记在实际听者账号。不会复制到用户“我的声音”，不接开发者钱包。
- 公开资源在服务端白名单中授权，客户端拿不到资源所有者、私有资源 ID、存储路径或授权凭据。
- 试听只读取预生成、校验哈希的 MP3，不创建 GPU 任务或扣用户额度。
- 公开音色额度服务异常、资源缺失、返回声音不匹配、词级时间戳缺失时停止并释放预留，不替换声音。
- 公开音色重试指纹包含语言与速度；客户端请求 ID 按段落、音色和朗读语言区分。

## 素材上线前仍需完成

1. 从已授权目录选取首批 12–20 个候选，确认精确来源 ID、源音频哈希、显示名称和描述。
2. 为 US/CN 各自准备消费端资源；完成持久化 prompt、各语言实际朗读试听、音频解码和词级时间戳检查。
3. 试听检查发音、重复/漏读与风格，使用真实账号验证 Pro、免费用户、额度为零、取消重试和阅读高亮。自动时间戳检查不能代替音质听审。
4. 完成源代码一致性核对后部署后端，在区域各自的 `VOICE_PUBLIC_LIBRARY_JSON` 发布合格清单；随后再准备 iOS 发布候选。

素材工具位于后端 `scripts/prepare-mobile-voice-library.ts`。默认仅验证输入与源文件哈希；`--prepare` 才会注册消费端资源、保存 prompt、生成试听及检查音频/时间戳，输出候选清单和私有证据，不自动发布。

本轮没有执行生产素材注册、批量生成或生产清单发布。模拟器中的 Rowan 为 DEBUG 界面验收数据，不能作为真实语音或跨语言音质的验收证据。
