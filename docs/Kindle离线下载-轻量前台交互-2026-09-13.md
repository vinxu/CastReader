# Kindle 整本图片下载：轻量前台迭代

日期：2026-09-13。以用户最新约束为本轮实施范围。源码基线为 `f5d6411`，发布祖先 `b6dd4d7`。

## 产品边界

从阅读器「更多 → 离线保存整本书」进入，沿用当前阅读器顺序采集整本原图。下载阶段不执行 OCR；本机播放时才执行 Vision OCR 和系统 TTS。当前迭代不引入独立下载器、后台传输、并行翻页或存储格式迁移。

下载期间保持 App 前台与屏幕唤醒，固定当前屏幕方向，用下载面板阻止阅读、翻页和字号等操作。这里的锁定是阅读界面锁定；普通系统锁屏或切到其他 App 会请求暂停，不是锁屏后台下载。iPhone 屏幕镜像所要求的手机锁屏，不作为后台能力证据。

## 用户流程

1. 进入面板后显示书名、图片保存说明和保持前台提示，用户点击开始。
2. 保存中显示同步动画、已落盘页数、百分比、体积、当前阶段和动态预计剩余时间。尊重系统减少动态效果设置。
3. 预计时间来自本次运行新保存页面的速度；续传不把旧页面计作新吞吐。首张图片提交后才开始记录速度样本，排除首次定位的一次性等待。最初数页显示「正在估算」，随后用近期样本更新并向上取整。30–60 秒是同书实测目标，不是界面固定承诺。
4. 「取消下载」弹出确认；「继续下载」关闭确认框，任务继续；确认取消后停止采集、保留已提交页面、恢复原阅读位置，再解除操作锁定，显示继续下载入口。
5. 顶部关闭在运行时弹出同一确认；「停止并关闭」等待恢复原位后关闭。恢复失败时保留提示，用户可以明确关闭。重复点击停止不会创建新任务。
6. 运行时禁止下滑关闭。退出前台自动请求暂停，回到前台后完成收尾；用户点击继续后从最后一个已提交页续传。已保存内容不删除，不自动重启明确取消的任务。
7. 整书源范围连续且所有资源校验通过后才完成。保存到最后一页后进入完整性校验和恢复原位阶段，过程中进度最多显示 99%。

取消与删除分开：本轮取消只终止本次运行并保留进度；不因用户关闭面板而删除已保存书籍。

## 本轮实现

- 原有下载协调器增加准备、保存、校验、恢复状态及停止原因；取消可等待收尾完成，空闲计时器和屏幕方向在收尾后释放。
- 保持每页先保存资源、再提交目录和书籍清单的顺序。源位置与图片身份仍核对，账号、版式、代次与连续覆盖检查保留。
- 合并旧图片身份读取与翻页调用，合并轮询中的源证据和图片身份读取，图片返回时同时带回源证据，减少 WebView 往返。保留原有稳定等待时长。
- 整书校验只读取一次页面索引，逐页仍检查图片与快照摘要、图片格式和快照版本；缺页、损坏资源和取消均停止校验。
- 记录每页采集与落盘毫秒数，供下一次真书测试判断瓶颈。不记录正文或账号凭据。
- 对页面未就绪的超时最多进行两次同页重试，重试时仍可取消，不提交空页或跳过目标页。若确认阅读器已空闲、但还停在目标页之前，一次重新定位同一目标页以恢复可能未生效的快速翻页；已到目标或仍在加载时不重复翻页。账号、版式、完整性等其他错误保持停止处理。
- DEBUG 合成测试书只验证下载界面，使用临时目录和非持久化 WebView，不是速度测量或真机验收证据。

## 验收顺序

| 项目 | 通过条件 |
|---|---|
| 准备时取消 | 不写入虚构页面；能够退出；恢复错误可见 |
| 保存时取消/关闭 | 已提交页保留；收尾结束前仍锁定；原位置恢复后退出 |
| 继续下载 | 从最后已提交页继续，不重复第一页、不丢页 |
| 前后台和旋转 | 保存期间方向固定；离开前台暂停；返回不自动启动新下载 |
| 完整性 | 整书连续范围通过；损坏图片不能标记完成；100% 不提前出现 |
| 阅读回归 | Kindle 位置与字号所有权回归、本机书籍跨页朗读与断点恢复通过 |
| 真书速度 | 同一设备、书和版式，明确源缓存条件；比较总耗时和分项耗时；下载 OCR 为 0 |
| 飞行模式朗读 | Wi-Fi 关闭的飞行模式下，打开尚未 OCR 的已保存页并首次朗读，人工确认声音和高亮 |
