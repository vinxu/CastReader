# CastReader for Mac 测试与验收矩阵

> 2026-10-04 实施范围更新：用户已明确 Mac **仅支持国际版**。全部实施与验收以 Global 为唯一 Mac 产品区域；iOS 既有中国区行为不改变。Mac 必须对齐最新国际版 iOS 的全部功能和实际效果，每个大功能完成测试与真实验证后，才进入下一个功能。执行事实以 `docs/mac-parity/progress.md` 和功能对齐表为准。

日期：2026-10-04，北京时间。状态：已执行 G01 基础验证；其余功能用例仍为 PLANNED。具体结果与未完成条件见 `mac-parity/progress.md` 及阶段报告。

本矩阵配套[功能实现测试与验收总规划](CastReader-Mac-Implementation-Plan-2026-10-04.md)，将 F01–F33 转换为可以逐项执行的测试。以下预期是待验证标准，不是通过记录。完整交付 R2 需要在冻结的支持范围内完成全部必需项；R1 只可排除跨设备新增功能，不能冒充 R2 验收完成。

## 1 执行规则

1. 每次执行记录精确候选：主 App、后端、Safari 宿主/扩展和配套移动端的 commit/包哈希、Build、配置、系统、架构、地区、测试账号别名和样本校验值。
2. 使用正常发布配置验证用户路径；fixture 仅用于可控契约/错误注入，并有发布包排除检查。
3. 除特定故障用例外，不修改真实用户数据，不清除用户原有书源会话。支付在正式支持的测试环境和测试账号内完成。
4. 核心Global×Read/Explain×基础/社区/私人声音矩阵必须逐格记录。其他组合按总规划第 8 节风险覆盖；表中一次测试名称不代表所有组合自动通过。
5. 单纯编译、请求 200、存在 DOM、出现高亮元素或保存截图均不等于端到端成功。真实音频、正确内容、可见高亮/标注和用户操作结果要形成对应证据。
6. 测试状态为 PLANNED / IN_PROGRESS / PASS / FAIL / BLOCKED / NOT_RUN / N/A。N/A 只用于明确不在已冻结支持范围的条件，写出理由；不能将失败改为跳过。
7. 严重失败修复后重跑失败项和相关影响范围；候选变化时先做源码差异分析，继承证据必须说明依据。

证据缩写：B＝构建/签名/xcresult，V＝真实画面与音频或操作录像，L＝脱敏结构化事件/请求记录，D＝目录/进度/账本/文件校验，P＝计时和资源测量。每项至少包含表列类型；涉及用户感知的 V 不能只以日志替代。

执行记录模板：

```text
case_id:
requirement_ids:
candidate_id:
environment: OS / architecture / region / source / voice / network
test_account_alias:
fixture_and_checksum:
preconditions:
actual_steps:
expected_result:
actual_result:
status:
evidence_paths:
issue_and_severity:
retest_candidate_and_result:
```
