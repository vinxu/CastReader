# 微信读书克隆音色停播与翻页恢复修复

2026-09-18。对应用户使用「曹操」朗读《茶花女》的两类停播。原始定位见 [诊断记录](weread-caocao-stop-diagnosis-2026-09-18.md)。

## 修复

1. **翻页后持续 409**：克隆请求身份同时绑定当前页面摘要、段落、实际朗读文本、语言和音色；页面替换、连续翻页和跨页携带提交均清理旧身份。完成回调按捕获的请求 ID 清理，避免用已变化的页面状态删除新请求。同页同内容的失败重试保留 ID，继续使用后端幂等计费保护。
2. **预读和前台请求差异**：两条路径统一使用克隆启动分段。HTTP 子请求 ID 由逻辑请求及实际文本、片段序号、音色、语言、速度等共同生成，防止相同序号对应不同文本时冲突。不改变服务端 409 校验，也不通过无限换 ID 重试掩盖错误。
3. **中文换音色后恢复失败**：为没有词时间戳的音频记录文本范围摘要。新声音拆段或合段时，核对此前完整文本和原片段内容，全部一致才从覆盖原片段起点的新音频边界播放。可能重读少量内容，不套用旧声音的秒数，也不跳过未读文字。文本确实变化仍拒绝错误定位；相同片段仍走原有准确/比例恢复。新增字段为可选，兼容已有存档。

修改范围为 `ReadingResumeCheckpoint.swift`、`ReadAloudViewModel.swift`、`TTSService.swift`，没有替换 WeRead/Kindle 导航、高亮、额度或播放器所有权子系统。
