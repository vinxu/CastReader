# CastReader 指标字典

> 版本：v0.1。本文定义指标，不定义具体 SDK、事件名称和数据库结构。

## 1. 通用统计规则

### 用户口径

- 未登录：按第一方随机 `anonymous_id` 去重。
- 已登录：按 `backend_user_id` 去重。
- 获得明确的合规依据并完成数据质量验证前，不把 email、Google sub、Apple user id 作为分析 ID。
- 同一用户跨端去重只使用服务端归一化后的 `backend_user_id`。

### 时间口径

- 原始事实统一记录 UTC 时间。
- 日 / 周留存按用户本地时区计算，并保存计算时使用的时区。
- 自然周暂定周一 00:00 至周日 23:59:59。
- 服务端接收时间与客户端发生时间同时保留，用于处理离线和延迟上报。

### 会话口径

- App 前台进入创建 `app_session_id`；持续后台超过 30 分钟后再回前台视为新会话。
- 朗读从用户发起播放开始，到主动结束、切换文档或超过 30 分钟无播放活动结束。
- 解读从用户发起解读开始，到完成、主动退出、失败终止或超过 30 分钟无活动结束。
- 短暂缓冲、锁屏和切入后台不自动结束阅读会话。

### 成功、取消和失败

- `success`：产品完成预期结果。
- `cancelled`：用户主动取消或离开，不计入系统失败率。
- `blocked`：权限、额度、登录或权益阻止继续，单独统计。
- `failed`：系统、网络、解析或服务端错误导致无法完成。

## 2. 北极星与价值指标

| 指标 | 定义 | 主要分母 / 去重 | 用途 |
| --- | --- | --- | --- |
| WMRU | 一周内至少完成一次有效阅读会话的用户 | 周去重用户 | 北极星指标 |
| 有效阅读会话 | 满足 5 分钟朗读、短内容 80% 完成、首个解读块 80% 完成或恢复后 3 分钟之一 | 会话 | 衡量真正获得价值 |
| 有效播放分钟数 | 音频真实播放状态累计秒数 / 60 | 用户、会话 | 衡量使用深度 |
| 人均有效阅读天数 | WMRU 当周有有效阅读的天数平均值 | WMRU | 衡量习惯强度 |
| 人均有效会话数 | 当周有效阅读会话数 / WMRU | WMRU | 衡量频率 |
| 内容完成率 | 完成内容数 / 已开始内容数 | 内容会话 | 观察读完能力；长内容需按长度分桶 |
| 恢复阅读率 | 成功恢复并继续 ≥3 分钟的内容 / 有可恢复进度且再次打开的内容 | 内容会话 | 衡量连续性价值 |

## 3. 首次激活指标

“新用户”初始定义为第一次生产环境启动的匿名或登录用户。重装去重只能在隐私规则允许的第一方身份范围内完成。

| 指标 | 定义 | 分母 | 注意事项 |
| --- | --- | --- | --- |
| 内容意图率 | 新用户 24 小时内选择任一内容来源 | 新用户 | 只打开首页不算 |
| 内容就绪率 | 成功进入可阅读状态的内容尝试 | 已确认的导入 / 打开尝试 | 用户取消不进入失败分母 |
| 首音成功率 | 朗读请求后首段音频开始播放 | 有效朗读发起 | 按来源、语言和节点拆分 |
| 解读首块成功率 | 发起解读后首个讲解块开始播放 | 有效解读发起 | 402 / 401 / 网络 / 解析分开 |
| 首次价值达成率 | 新用户 24 小时内完成有效阅读会话 | 新用户 | 核心激活指标 |
| 导入到首音耗时 | 确认内容来源到首段播放的时长 P50 / P90 / P95 | 首音成功会话 | 不只看平均值 |
| 首开到首次价值耗时 | 第一次启动到首次有效阅读完成 | 已达成首次价值的新用户 | 用于比较入口和 onboarding |

## 4. 使用与功能价值指标

### 朗读

| 指标 | 定义 | 观察维度 |
| --- | --- | --- |
| 朗读发起率 | 进入阅读器后发起朗读的内容会话占比 | 来源、语言、新老用户 |
| 3 / 10 / 30 分钟到达率 | 有效播放达到对应阈值的朗读会话占比 | 来源、内容长度、免费 / Pro |
| 后台播放使用率 | 有过锁屏或后台有效播放的朗读会话占比 | 新老用户、内容来源 |
| 播放完成率 | 音频播放达到内容可朗读范围 80% 的会话占比 | 内容长度分桶 |
| 主动停止率 | 用户明确停止的会话占比 | 播放时长阶段、停止入口 |
| 异常中断率 | 非用户意图导致播放结束的会话占比 | 错误类型、版本、节点 |
| 音色试听到选用率 | 试听后在同一或后续阅读会话中选用该音色 | 语言、免费 / Pro、音色 |
| 速度调整后持续率 | 调速后继续播放 ≥3 分钟的会话占比 | 速度区间 |

### 解读

| 指标 | 定义 | 观察维度 |
| --- | --- | --- |
| 解读发起率 | 可解读内容会话中发起解读的占比 | 场景、来源、新老用户 |
| 首块完成率 | 首个讲解块播放达到 80% 的解读会话占比 | 场景、语言、等待时间 |
| 第二块继续率 | 首块完成后开始第二块的会话占比 | 场景、内容长度 |
| 解读完成率 | 已生成范围内所有讲解块播放完成 | 场景、块数分桶 |
| 标注有效展示率 | 有计划标注的解读块中至少一个标注成功锚定并展示 | 来源、mark 类型 |
| 朗读 / 解读切换率 | 同一内容会话内切换模式的占比 | 初始模式、内容来源 |

### 内容来源

必须分别观察：Kindle、PDF、EPUB、DOCX、TXT、网页 URL、照片 / 相册 OCR、粘贴文本、剪贴板提示、历史恢复。

来源维度只记录枚举，不记录文件名、书名、网页完整 URL、OCR 或正文内容。

## 5. 留存指标

留存只以“再次完成有效阅读”为成功，不以再次打开 App 为成功。

| 指标 | 定义 | Cohort |
| --- | --- | --- |
| D1 有效留存 | 首次价值次日再次完成有效阅读 | 首次价值日新用户 |
| D7 有效留存 | 首次价值后第 6～8 天至少一次有效阅读 | 首次价值日新用户 |
| D30 有效留存 | 首次价值后第 27～33 天至少一次有效阅读 | 首次价值日新用户 |
| 次周留存 | 首次价值所在周的下一自然周成为 WMRU | 首次价值周新用户 |
| 周频率 | 每周有效阅读 1 天、2～3 天、4 天以上用户分布 | WMRU |
| 同内容恢复留存 | 回访用户继续上次内容并达到 3 分钟 | 有未完成进度用户 |
| 新内容扩展率 | 首次价值后 7 天内开始第二份内容 | 已激活用户 |

同时保留“App 打开留存”作为诊断指标，但不得代替有效阅读留存。

## 6. 质量指标

| 指标 | 定义 | 必须拆分 |
| --- | --- | --- |
| 内容处理成功率 | 内容成功转换为可阅读文档 | 来源、格式、大小桶、错误阶段 |
| OCR 成功率 | 拍摄 / 选图后得到至少一个可读段落 | 权限、无文字、识别失败 |
| Kindle 绑定成功率 | 开始绑定后完成书架同步 | 登录取消、页面异常、同步错误 |
| Kindle 打开成功率 | 点击书籍后进入可朗读正文 | 恢复 / 首开、横竖屏 |
| TTS 请求成功率 | 有效请求返回至少一个可播放 segment | 节点、语言、音色、HTTP 类别 |
| TTS 首段延迟 | 发起到首段可播放 P50 / P90 / P95 | 节点、语言、来源 |
| 解读首块延迟 | 发起到首块可播放 P50 / P90 / P95 | 场景、语言、服务阶段 |
| 队列等待率 | 播放追上生成、进入等待下一段的会话占比 | 网络、速度、节点 |
| 自动恢复成功率 | 可重试错误后自动恢复且继续播放 | 错误类型、重试次数 |
| Crash-free 用户率 | 未发生崩溃的活跃用户占比 | 版本、系统、设备类 |

错误属性只允许结构化类别和经过清洗的错误码，不上传用户正文、完整 URL、服务端原始响应或可能含个人信息的日志。

## 7. 付费与收入指标

### 付费页

付费页必须区分触发原因：

- 朗读额度耗尽；
- 解读次数耗尽；
- Pro 音色；
- 速度超过免费上限；
- 设置页主动升级；
- 其他未来权益。

| 指标 | 定义 | 分母 |
| --- | --- | --- |
| 合格付费页触达率 | 至少完成首次价值后看到付费页的用户 | 已完成首次价值用户 |
| 过早付费页率 | 尚未完成首次价值就看到付费页的用户 | 新用户 | 重要护栏指标 |
| 套餐查看率 | 付费页中实际看到套餐区域 | 付费页有效曝光 |
| 购买发起率 | 点击购买并开始 StoreKit 流程 | 付费页有效曝光 |
| 购买成功率 | 成功获得本地有效权益 | 购买发起 | 取消和失败分开 |
| 付费页净转化率 | 购买成功用户 | 付费页有效曝光 |
| 触发原因转化率 | 每种触发原因下的购买成功率 | 对应触发曝光 |
| 月 / 年套餐选择率 | 各套餐购买发起与成功分布 | 购买用户 |
| 首次价值到购买时长 | 首次有效阅读到首次购买成功的时间 | 首次购买用户 |
| 购买前价值量 | 购买前有效分钟、有效会话、解读块数 | 首次购买用户 |

### 购买后

| 指标 | 定义 | 数据权威 |
| --- | --- | --- |
| 购买后 D7 / D30 使用率 | 购买后窗口内至少一次有效阅读 | 产品数据 + 服务端权益 |
| 首次续订率 | 首个订阅周期结束后成功续订 | 商店服务端事实 |
| 取消自动续订率 | 当前周期内取消续订意图 | 商店服务端事实 |
| 退款率 | 退款交易 / 成功交易 | 商店服务端事实 |
| 付费流失率 | 权益到期且未续订用户 | 统一 entitlement |
| 跨端权益一致率 | 同一用户各端判权一致的检查占比 | `/api/pro/status` 与平台权益 |

金额类指标必须明确毛收入、税费、平台分成和净收入的差异。产品分析不自行推算财务收入，以 App Store / Stripe 财务与服务端交易事实为准。

当前 iOS 端 StoreKit 权益是本地权威，后端尚没有完整 Apple 收据校验与订阅生命周期闭环。因此在服务端交易事实补齐之前，可以分析客户端购买流程和即时解锁，但不能把客户端回调当作续订、取消、到期和退款的最终口径。

## 8. 分群维度白名单

- `client_platform`：iOS、Android、浏览器扩展、Web、macOS；
- `client_variant`：Chrome、Edge、Firefox、Safari、App Store 等受控枚举；
- `client_version` 与可选 build；
- `product_area`：朗读、解读、Reader、账号、付费；
- `surface` 与 `entry_point`：端内受控入口，不使用含义过载的通用 `source`；
- OS 主版本、设备大类；
- 新用户 / 回访用户；
- 匿名 / 登录；
- Free / StoreKit Pro / Server Pro；
- 内容来源与格式；
- 内容长度分桶，不记录正文；
- 朗读 / 解读及解读场景；
- 朗读语言、界面语言；
- 音色 code、tier、gender、accent 等公开 catalog 元数据；
- 付费触发原因；
- 国家 / 大区级商店信息（如合法且必要），不采集精确位置。

禁止的属性见《CastReader-数据采集与隐私边界.md》。

平台是统一分析维度，不是把所有端的交互事件混成一套。跨端核心价值阶段使用统一口径，端内入口、权限、提取和渲染阶段分别保留。

## 9. 指标变更治理

每个核心指标需要保存：

- 指标名称和版本；
- 业务负责人；
- 精确定义、分子、分母；
- 数据来源；
- 去重和时间窗口；
- 排除条件；
- 可用分群；
- 生效日期和变更原因。

北极星、激活、留存和收入指标改变口径时必须升版本，并保留旧口径一段对比期。
