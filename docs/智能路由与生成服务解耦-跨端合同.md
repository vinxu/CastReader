# 智能路由与生成服务解耦：跨端合同

> 2026-08-15。适用 iOS / Android / 后端三方。端点状态为当日直连实测。
> 后端与 Android 均已上线并经生产端到端验证（§6）。本文档可直接交给 iOS Agent 实施 §5。

## 1. 目标与原则（产品口径）

1. **发行版本定产品**：Google Play 下载走国际发行版，中国应用市场下载走中国发行版。
   登录通道、支付渠道、书架呈现、YouTube 有无由它决定。**支付永远跟发行版本**：
   中国版无论人在哪都是支付宝、打备案网关；Play 版永远 Play Billing。
2. **用户位置定生成线路**：朗读（TTS）与解读（QuickRead）的正文落点由「人此刻在哪」
   决定——在中国就进境内网关，在境外就走全球网关，与装的是哪个版本无关。
3. **流畅优先，零跨程**：生成流程一旦进入某条线路，全程不跨境；判定失败安全回落
   global（宁可境内用户慢，不能把境外正文送进境内网关）。

## 2. 三层模型

| 层 | 决定于 | 管什么 | 生效期 |
|---|---|---|---|
| 发行版本 | 下载渠道（编译期 / storefront） | 产品面、支付、登录通道 UI | 安装期 |
| 账号域 | 发行版本（会话签发网关） | `cms_` 会话、Pro、额度、埋点、文档、上传 | 会话期 |
| 生成线路 | 用户位置，冷启动冻结 | TTS 合成+目录、QuickRead 四端点、试听/头像物料 | 单进程 |

位置判定信号（客户端，优先级递减）：Debug 覆盖（仅 Debug 构建）→ 网络国家码
（漫游跟人走）→ SIM 归属 → 大陆时区（港澳台不算）→ 默认 global。不用系统语言。
**服务端权威升级**：`GET /api/mobile/network-region/v1`（无鉴权）返回平台观测的
`countryCode / mainlandChina / ingress`——全球入口由 Vercel GeoIP 提供，CN standalone
刻意返回 `null`（那台没有平台级 GeoIP，不信任任何 header）。客户端可在冷启动用它
校准本地信号；不可用时本地链独立成立。

## 3. 核心机制：跨线路算力凭据（`cmc_`）

解读入口只认 `cms_` 会话，而会话按网关隔离。跨格（Play 版在华、中国版出境）由
**compute handoff** 解决：在**账号自己的网关**上，用 `cms_` 换一张短命、受限、
指向对侧线路的算力票 `cmc_`，再拿它去对侧解读入口消费。两台部署共享会话表，
跨部署验证天然成立。

### 3.1 铸造

```
POST {账号网关}/api/mobile-auth/compute-session
Authorization: Bearer cms_…          X-Auth-Provider: session
{ "audience": "quickread", "targetRoute": "cn" | "global" }

→ { "code": 0, "data": { "token": "cmc_…", "expiresAt": ISO8601,
                          "audience": "quickread", "targetRoute": … } }
```

- **严格跨线**：`targetRoute` 必须 ≠ 账号入口线路；同线请求 422
  `INVALID_COMPUTE_SESSION_REQUEST`（同线由普通 `cms_` 直接服务）。
- TTL 15 分钟；幂等——剩余寿命足够时重复请求返回同一张票。
- 配额记在 `accountRoute`（发行侧）头上：global 账号用境内算力扣 global 配额，反之亦然。

### 3.2 消费

```
POST {对侧解读入口}/api/quickread/…
Authorization: Bearer cmc_…          X-Auth-Provider: compute-session
```

错误语义：401 `COMPUTE_SESSION_EXPIRED`（过期→重铸）、`COMPUTE_SESSION_SCOPE_MISMATCH`
（票与入口不符）、`AUTH_PROVIDER_REQUIRED`（头缺失）。`cmc_` **永不**被账号、Pro、
支付、文档、上传接受——只解读一个 audience。

### 3.3 客户端调用序（跨格时）

```
冷启动冻结生成线路 → 解读请求前：线路 == 账号线路 ?
  是 → 直接 cms_ 打本线入口
  否 → （缓存有效 cmc_? 复用 : 向账号网关铸造）→ cmc_ 打对侧入口
      → 401 EXPIRED → 重铸一次 → 仍失败 → 显式报错（不回退跨境）
```

## 4. 四格矩阵（目标态，后端部署后全绿）

| | 人在中国 | 人在境外 |
|---|---|---|
| **中国版** | 全部境内（cms_ 直连） | 朗读 `.ai`；解读 `cmc_`→`.ai` 统一入口；账号/支付宝仍 `.cn` |
| **Play 版** | 朗读 `.cn`（合成免会话）；解读 `cmc_`→`quickread.cn`；账号/Play 仍 `.ai` | 全部 `.ai`（cms_ 直连） |

TTS 合成与目录免会话、纯按位置；目录连带试听/头像物料自动同线。

## 6.5 CN 解读性能与跨境残留（2026-08-15 实测）

逐跳测量结论：**设备→境内网关→回环 worker→DeepSeek 全程境内**（DeepSeek 解析到
211.95.70.108，DNS 4ms/连接 7ms）；giphy 无 key 自动跳过（fail-fast，零外呼）。

**唯一跨境残留 = 控制面共享库**：`aws-1-us-east-2.pooler.supabase.com`，盒子 RTT
381ms。每次解读调用做会话验证（1 往返）+ 续传作业查询（1 往返），整场解读约
3–5 秒纯跨境延迟。传的是会话/作业元数据非正文，但按零跨境目标仍待消除
（方向：CN 侧短 TTL 会话缓存或区域读副本）。

**慢的主因是模型输出量 × 吞吐**：单块输出 ~3000 tokens；v4-flash 93 tok/s ≈
33s/块，v4-pro（产品意图档）49 tok/s ≈ 61s/块，5 块串行即 3–5 分钟。国际版同一
份代码不慢，因为 Gemini 3.5 Flash 吞吐更高 + 库同区零税。结构优化已对齐
（fast-block0、done 先行、GIF 异步、early block stream 两端都启用）。

修复杠杆（按见效比）：① compose 输出合同压缩（模型只回短引文，worker 本地定位
偏移）→ 单块降至 ~8–12s，**唯一能进秒级的杠杆**；② 客户端块间并行；③ CN 控制
面近端化；④ 模型档位为产品决策（pro=质量 / flash=2× 速度）。

## 7. 不变量（评审红线）

- `cmc_` 只解读、只跨线、15 分钟、配额记账号侧。
- 支付、账号、上传、文档永不接受 `cmc_`，永不跨线路由。
- 生成流程内无跨线回退；判定 fail-closed 到 global。
- 线路进程冻结；登录/支付/上传/生成中禁热切。
- Release 无视一切本地路由覆盖。
