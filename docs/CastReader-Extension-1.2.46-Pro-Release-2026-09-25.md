## 修复范围

- 同步 Pro 到期与撤销状态，阻止旧状态/迟到响应恢复已失效权益；QuickRead 402 类终止路径释放播放器占用，之后可再次 Listen。
- 解读选择克隆音色后退出登录，或服务可靠确认失去克隆权限时，按解读语言回退免费默认音色继续。播放器名称、偏好和缓存元数据随实际音色更新。
- 每个未播放解读单元只允许一次权限回退；已经产生部分克隆音频时，丢弃该单元未播放部分，以默认音色完整重建，避免混用时间轴。正在播放的单元不强制打断。
- 超时、429/5xx 和音质失败不解释为失去权限，不随意换声；免费额度照常生效，音色回退不授予 Pro。没有增加逐段会员查询。
- 修复阅读六组文案与主 UI 使用统一语言解析；中文、英语、日语、西班牙语、法语、德语、意大利语、葡萄牙语、印地语均覆盖。
- 网站明确区分网站会话与扩展会话；选择账号后，仅收到匹配账号的扩展成功回执才显示完成。超时、失败与旧账号回执可重试，九语言登录链接与私有账户页路径一致。
