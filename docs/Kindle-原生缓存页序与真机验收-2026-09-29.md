## 实现

`KindleNativePageScript` 结构化查找当前 React 分支的 `navigationService`，只读 `rendererController.cache` 中已经存在的 Promise。使用 **`currentIndex ± 1`** 作为上下页关系；不调用会改变渲染游标的 `getPageByRelativeIndex`，不按 Blob 创建顺序、Map 插入顺序、DOM 顺序或批次局部 `pageIndex` 推断相邻页。

每张图片归属 **Web 文档实例 + 书籍 + 导航控制器/渲染器代次 + 相对索引 + 缓存槽位修订号**。Promise 返回、图片捕获、OCR 完成、提交语句前分别校验当前槽位所有权；缓存替换、驱逐、重排后的旧任务不能覆盖新页。捕获窗口只保留原生索引 `current−1…current+2` 的页面引用，读取已经解码的 image/canvas，不要求原始 Blob URL 仍然有效。旧 Blob 内容缓存的摘要也改为完整字节 SHA-256。

翻页只发送一次语义 `NextPage` / `PreviousPage`；带请求 ID 防重复分发。成功条件是目标索引、缓存页对象、`currentView.renderedPage` 及实际挂载图面一致。相同像素的两页也可以确认，原生确认不再强制等待两次 200 ms 像素变化采样。未准备好 `+1` 时不能拿 `+2` 顶替。

这层接入现有整句缓冲、24 秒音频预取、持续播放 VM 和来源词高亮。下一页 OCR 提前准备，只有实际确认相邻页面后才将其正文并入音频；来源词决定何时呈现新页面。iPhone 默认启用；iPad 保留既有路径。其他阅读器没有改动。

## 实测中发现并修复的兼容问题

r2 字号 4→5 后，旧位置恢复逻辑仍搜索旧布局的像素指纹；搜索失败只尝试按旧 Blob 键滚回，而起始页已经离开缓存窗口，导致停在后四页。这次失败保留在 `r2-reflow-search-failure.log`，没有计为通过。

r3 修正两个出口：关闭字号设置创建新的当前页导航意图，下一次 Play 不搜索旧像素；冷启动位置搜索未命中时，在同一书籍、原生代次中按逻辑索引逐页退回初始位置。若代次改变或不能确认退回则终止此次准备，不从搜索末页误播。图片缓存的生命周期不再决定导航起点能否恢复。

## 验证记录

全程只使用连接的 **iPhone 15 Pro Max / iOS 26.7 (23H24)** 与 iPhone Mirroring，未使用模拟器。

- Node 执行实际打包 JavaScript：5,000 次随机缓存变更、20,000 次页面所有权检查；覆盖乱序 Promise、槽位替换、驱逐、重排、当前 React 分支、重复分发、相同图片页、撤销 URL、离屏 canvas、缺失直接邻页。旧离线捕获四组回归通过。
- r2 真机 XCTest：86 项通过、0 失败、0 跳过，包括 4 项实际 WKWebView 原生缓存测试。
- r3 修改重排恢复后：受影响的 45 项真机测试通过，含新增的当前页重排与逻辑索引回退用例；这些计数与 r2 重叠。r4 对设置测试进一步隔离 UserDefaults/历史库，34 项再次通过。
- r2 私人克隆音色 3× 连续窗口 **01:47:09–01:51:19**：实际自动呈现 13 个下一页，原生索引逐页推进；同一播放会话，0 错序/取页失败。33 次 AVPlayer 切换中位 208 ms、最大 258 ms，没有 >600 ms 样本；38 次 TTS 请求无重复 `(paragraph, part)`。
- r2 暂停后 Next/Previous 一次往返、Next×3/Previous×3 及左右滑动，均回到原页。后台已持有下一页时，手动 Next 采用该页，没有再次多跳。

时间指标来自 AVPlayer 状态事件，**不是声学静音采样**，也不代表任意网络、任意书籍均能保证绝对零停顿。

### r6 冷启动位置恢复入口

r5 冷启动实际恢复到先前听到的段落后，当前页末出现 `READ document finished`，并未请求后续页。根因是 VM 初始化/书籍元数据绑定已经恢复 `currentParagraphIndex`，而 `configureKindleContinuousInput` 仅接受索引 `<0`，返回 nil 后外层没有阻止开始播放，误按有限文档运行。r5 此次窗口没有计为连续翻页通过。

修正为在 VM 尚未激活、生成代次为 0 时接入源生产者，允许已经定位的保存游标；已有源不能重复接入。外层必须取得 input token，否则明确结束此次准备。新增真机 HTTP fixture 测试从保存的第 2 段启动，确认不重播第 1 段、页末仍等待源、追加下一页后继续并且只请求一次。

r6 独立真机包编译通过，114 项真机回归全部通过（连续输入 8、预取 17、位置恢复/音色 89）。已安装并于 02:40:26 启动，调试库 UUID `8187388B-B393-37E8-9942-190BC48753F2`。实际书籍窗口为 02:42:59.582–02:45:52.910：实际呈现 8 个下一页，原生代次 2 索引依次 1…9（最后一页预取保留），同一 VM 无 source-failed。23 次 AVPlayer 切换中位 168 ms、最大 243 ms，没有 >600 ms 样本；31 次 TTS 请求按音色代次/段落/part 无重复。02:44:01.197 从私人克隆切换 Bella，下一单位预取于 02:44:01.223 启动，早于当前新音色单位生成完成；切换后的首个衔接为 154 ms。主动切换音色本身的重新生成等待约 3.9 秒单列，不计入连续队列间隔。
