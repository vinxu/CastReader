# CastReader 移动端商店隐私申报清单

日期：2026-07-14
适用版本：iOS 1.2.9 (19)、Android 1.0.11 (15)

本清单与当前客户端事件契约、后端 `/api/events` 严格校验及线上隐私政策保持一致。商店后台提交时须按本清单复核，不能仅依赖包内声明。

## 共同边界

- 第一方收集，不出售、不用于广告、不做跨公司追踪。
- 传输使用 HTTPS。
- 事件可携带随机设备 ID；登录后可携带后端账户 ID，因此相关使用/诊断数据按“可关联用户”申报。
- 产品统计明确拒收正文、OCR 文本、图片、文件名、标题、URL、来源页、邮箱、原始错误和响应正文。
- 朗读/解读正文属于用户主动请求功能时的服务端处理，不进入分析事件；按商店规则仍需作为用户内容/文件文档申报。
- 统计事件最长保留 12 个月；账户/订阅和用户内容的保留规则以线上隐私政策为准。

## Google Play Console — Data safety

总览建议答案：

- Does your app collect or share user data? **Yes**
- Is all user data encrypted in transit? **Yes**
- Can users request deletion? **Yes**（隐私政策中的联系邮箱与账户删除入口）
- Is data shared with third parties? **No**（支付/登录/基础设施服务提供方按 Google 的 service provider 口径处理；提交时仍需结合 Play Console 当期问法复核）

| Google Play 数据类型 | Collected | Shared | Required/Optional | 用途 |
|---|---:|---:|---|---|
| Personal info — Name | Yes | No | Optional（登录） | App functionality, Account management |
| Personal info — Email address | Yes | No | Optional（登录） | App functionality, Account management |
| Personal info — User IDs | Yes | No | Optional（登录） | App functionality, Analytics, Account management |
| Device or other IDs | Yes | No | Required | App functionality, Analytics |
| Financial info — Purchase history | Yes | No | Optional（购买） | App functionality, Analytics, Fraud prevention/security |
| App activity — App interactions | Yes | No | Required | Analytics |
| App info and performance — Diagnostics | Yes | No | Required | Analytics |
| App info and performance — Other app performance data | Yes | No | Required | Analytics |
| Files and docs | Yes | No | Optional（用户导入/朗读/解读） | App functionality；服务请求所需处理 |
| Other user-generated content | Yes | No | Optional（输入文本/朗读/解读） | App functionality；服务请求所需处理 |

照片/相机 OCR 在设备本地进行，图片不进入产品统计。若后续任何功能开始上传原图或截图，必须在发版前把 Google Play 的 Photos and videos 及 App Store 相应数据类型补上。

## 提交前人工复核

1. 打开线上中英文隐私政策，确认日期为 2026-07-14 且可公开访问、无登录墙。
2. App Store Connect 的 App Privacy 逐项与上表一致。
3. Google Play 的 Data safety 逐项与上表一致。
4. 若商店后台已有旧答案，先更新并保存，再选择新构建提交审核。
5. 截图保存最终申报页面，作为本版本验收证据。
