# Consumer cancellation runtime, October 15, 2026

The HTTP disconnect propagates from alignment through the original shared worker to the existing Nari engine. A cancelled callback retains its GPU scheduler slot until the exact attempt, lease, engine instance and audited engine source report retirement. The engine is not preempted mid-CUDA operation. Multiple consumers share one producer; cancelling one does not stop the remaining consumer. Unknown acknowledgements retain ownership and may require operator recovery; they never trigger another model or synthesis retry.

`source-manifest.json` binds the exact changed runtime sources. Worker files are canonical under `../worker`; alignment files and the Nari wrapper are preserved here. The deployment retains existing developer streaming, registration dependencies, models, queue, voice data and authentication. Copies of `consumer_cancellation.py` and `consumer_nari_ack.py` are required beside the worker and Nari wrapper. The installer and shared-service guard must explicitly pin the new scheduler and worker hashes.
