# 离线书籍：中日文分句高亮、设置入口与本地封面

日期：2026-09-13。源码基于 `58a73a2` 增量修改，发布祖先 `b6dd4d7` 已由集成脚本检查；未改动在线阅读恢复、翻页确认和原生字号重排子系统。

## 本轮行为

- 入口移至个人设置：账号 → 订阅 → 蓝色「离线书籍」模块。首页不再展示离线下载卡片。设置中打开书籍会收起设置页，呈现全屏离线阅读器；收起阅读器仍保留 Mini Player。
- 中文和日文由系统朗读的真实回调驱动句子／分句高亮，按逗号、顿号、分号及句末标点分组，保留对应的闭引号。英文继续按单词高亮。文本和原页面叠加使用同一高亮范围。
- 展示范围与朗读断点分开：调整倍速仍从实际朗读游标继续，不会因为整句高亮而重读整个分句。相同分句中的逐字回调不再重复发布高亮更新。
- 下载时同时保存封面，优先将现有书架图片缓存持久化，必要时独立请求封面，页面保存无需等待封面网络请求。停止下载时同步取消封面请求。
- 封面与书籍图片一起存在 Application Support 的账号和书籍 generation 目录内，校验尺寸、字节数和摘要，原子写入。缩略图按原比例缩至最长边 600 像素，列表与 Mini Player 使用本地图片、等比完整显示。
- 旧书首次打开离线列表会自动补封面：先读本地封面／书架缓存；联网时补取书架原封面；暂时无法取得时使用已保存的第一页作缩略图，联网后可升级。无需重新下载整本，补图不修改页序、阅读位置或列表排序。
- 列表搜索放在顶部，列表控件字号上限与现有离线阅读控件一致（accessibility1），避免极大系统字号下搜索栏和说明挤占封面区域。

## 验证

累计通过 62 个不同核心用例：KindleOfflineBookReaderTests 21、KindleOfflineBookStoreTests 25、SystemSpeechPlaybackTests 16。覆盖已有书兼容、断点／页序、纯本地 OCR、语音选择、倍速真实生效、旧回调隔离、中文分句、日文 UTF-16／引号、封面持久化和损坏恢复、账号隔离及删除后的迟到请求。

累计通过 5 类不同 UI 流程：

1. 中文图片整本保存 → 端上 OCR → 中文语音 → Mini Player → 返回阅读。
2. 日文图片本地 OCR → 日文语音和句子高亮。
3. 实际 SettingsView 中订阅下方入口 → 带封面的本地书 → 阅读 → Mini Player 暂停／展开／停止 → 再次打开。
4. 播放过程中更改倍速，验证当前 utterance 的实际速率变化。
5. iPhone SE 小屏、深色、最大辅助字号下进入设置并滚动找到入口，确认封面完整可见、不与搜索栏相交、阅读页可操作。

测试先后在 iPhone 17 Pro 与 iPhone SE（第三代）模拟器执行。中途一次 CoreSimulator 服务退出导致测试运行器启动失败；重启现有模拟器后复跑通过。极大字号测试最初发现懒加载 Form 行的测试定位问题，修复滚动定位后继续视觉检查，又修复列表字号与搜索栏布局。不能将早期失败记录解读为最终通过记录。

原始日志和 xcresult 路径、真机安装摘要见同目录 `offline-settings-covers-cjk-validation-20260913.json`。截图仅保留合成测试书和未登录的设置界面，不包含用户书籍页面及账号资料。
