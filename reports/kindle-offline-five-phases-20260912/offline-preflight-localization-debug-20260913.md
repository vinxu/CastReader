# 离线功能上线前审查：文案、本地化与调试入口

日期：2026-09-13。基于 `a12af65` 增量修复，已验证发布祖先 `b6dd4d7`。没有合并 AO3、归档、上传或送审。

## 审查范围与修复

覆盖「更多」菜单、整本下载、进度／重试／取消／空间不足／完整性失败、下载完成指引、设置入口、离线书库／删除确认／损坏副本、播放器／原页面／倍速／本机语音、Mini Player，以及 Kindle 与设置中的调试入口。共检查 186 个文案键，覆盖应用已支持的 9 种语言：简中、英、日、西、法、德、巴西葡语、意大利语、印地语。

- “更多”的离线标题此前是普通 String，菜单直接显示中文。改为 `String.LocalizationValue`，渲染时按应用所选语言本地化。
- 补齐 133 个文案键的多语言资源，包括运行状态、错误、空状态、页数／剩余时间与 VoiceOver 名称。紧凑数量标签使用不依赖单复数的写法；格式占位符逐项核对。
- 修复设置入口的网络状态文案、Mini Player 播放／暂停名称的动态字符串路径。
- 下载完成指引从已移除的首页入口改为 Settings → Offline Books，各语言与实际界面名称一致。
- 恢复旧下载记录时，不再直接显示存储在旧记录中的旧语言错误文案；用当前语言说明未完成状态，保留页面和续传入口。当前下载中的具体错误仍照常显示。
- 倍速数值按应用语言格式化，例如法文／德文显示 `1,0×`。
- 德文最大辅助字号截图发现按钮文案截断，改为完整换行、占满可用宽度；下载面板控件字号上限与现有离线控件一致。长说明位于可滚动内容区，操作按钮位于安全区域内。

## 调试入口

`DistributionTestingPolicy.showsDebugPanels` 默认关闭，只有 DEBUG 构建且本次启动显式传入 `-CastReaderShowDebugPanels` 才开启。它不是持久设置、账号权益或可由历史 UserDefaults 解锁的入口；Release 恒为 false。

已隐藏 Kindle 阅读器右上角试管按钮、书架图片缓存验证／独立页面测试入口、设置模拟 Pro／重置引导／内部区域与线路面板。原有 DEBUG-only 诊断与合成书测试机制保留供明确的内部启动使用，Release 中不包含这些入口。没有改变生产线路或会员判断逻辑。

## 验证证据

- 静态与编译产物本地化审查通过：186 个键 × 9 种语言，无漏项、未完成翻译、占位符不匹配或中文回退。负例检查确认脚本能拒绝漏日文翻译与数字占位符被误改为字符串。
- 9 种语言的 UI 流程全部通过：更多 → 下载面板 → 设置入口 → 本地封面书库 → 阅读器。测试刻意让系统语言保持英文、应用选择其他语言，检查应用语言切换是否真正生效。
- 共 13 个不同 UI 用例通过，额外覆盖默认设置无调试模块、德文最大辅助字号、旧下载记录由中文切到英文、播放中的倍速变更。针对德文按钮截断修复，复测了大字号德文与正常字号印地文。
- 两项现有分发策略回归通过：App Store 升级忽略持久测试线路覆盖，以及覆盖权限依据分发环境判断。
- Release 配置构建通过；实际 Release 模拟器 app 的 116 个文件经过 50 个测试／调试标记扫描，无命中。Debug app 作为阳性对照能检出合成测试载荷；Release 的内部发行开关为 NO。
- 真机镜像人工检查：英文界面下，已有 Kindle 书右上角试管图标已隐藏；“更多”显示 Save Entire Book Offline；734 页完整本机副本的面板文案、页数与设置入口指引正确；设置中的蓝色 Offline Books 位于订阅下方，3 本已有书均显示本地封面。真机完整设置底部的隐藏检查由模拟器实际 SettingsView 测试和 Release 扫描补充，未将镜像未能滚动的操作算作通过。

详细日志、测试方法、构建摘要及安装结果见 `offline-preflight-validation-20260913.json`。界面证据只保存合成测试书，不保存真机账号或用户书籍页面截图。
