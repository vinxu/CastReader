# Kindle 离线保存与阅读：完整链路本地验收

日期：2026-09-13。实现父提交 `21cbaf6`，发布祖先 `b6dd4d7`。工作树为 `CastReader-kindle-offline-five-phases-20260912`。用户本轮要求先完成本地及模拟器验收，最后再使用手机；本轮没有安装或操作真机。

## 用户流程

| 步骤 | 入口与行为 |
|---|---|
| 保存当前书 | Kindle 阅读页 → 更多 → 离线保存整本书；保存图片，不在下载阶段做 OCR |
| 下载过程 | 显示已保存页数、百分比、容量、剩余时间估算和同步动画；提示保持前台，期间屏幕保持唤醒、阅读操作锁定 |
| 取消或退出 | 显式确认继续或停止；停止时保留已提交页面并恢复原在线位置，恢复失败留在界面提示，不隐藏失败 |
| 失败恢复 | 展示错误和已保留页数，可继续保存，也可先阅读已保存部分；未完成不能显示“整本已保存” |
| 打开本机书 | 下载完成页直接打开；之后可从文库 → 离线书籍或 Kindle 书架进入，无需先打开在线阅读网页 |
| 本机书籍列表 | 区分整本与未完成、展示容量与上次阅读页，支持搜索、继续下载、删除确认及损坏副本提示 |
| 阅读原页 | 首次打开直接显示保存的图片；可前后翻页、跳页，并打开原页放大，支持捏合与双击缩放 |
| 开始朗读 | 点击播放才调用本机 Vision OCR 与系统 TTS；已识别内容可切换朗读文本和原页面，高亮跟随系统范围回调 |
| 阅读控制 | 播放/暂停、前后句、前后页、声音、速度、回到朗读位置、阅读设置、睡眠定时；图片视图使用固定版式设置语义 |
| 断点恢复 | 保存页、句首、声音和速度；退出或重启后恢复但不自动播放，正文滚动到保存句所在段落 |
| 已存部分末尾 | 明确提示剩余页面未下载，提供继续下载入口；完成书末尾显示读完及重新阅读入口 |
| 删除本机副本 | 确认弹窗明确列出“取消”和“删除本机副本”；仅删除此账号此书的本机资源及离线进度，迟到的 OCR/进度写入不能复活副本 |

系统 TTS 恢复按已确认句首定位，允许重播当前未完成的一句；不将这一恢复语义等同于重复保存或乱序播放页面。

## 实现与迭代

- 将离线列表与阅读界面拆分为独立 SwiftUI 文件，仍使用原有下载协调器、逐页完整性校验和系统语音服务。新增 Swift 文件均已登记到工程。
- 续传入口携带书籍来源元数据及账号边界校验，复用现有 Kindle 阅读器打开下载面板；没有新建独立下载器。
- 删除清单先于资源删除，使旧任务写入失效；索引中的新增来源和速度字段可选，兼容旧副本。
- 暂停撤销已经排队的自动翻页；换页失败清空旧正文和语音单元，避免旧页内容显示在新页码下；重开已删除副本不保留旧正文或音频。
- 原图按页解码并缓存，避免每个高亮回调重复解码。
- 模拟器发现部分书末尾按钮位于播放栏下方、点击会误触声音入口，已改为正文和播放栏分别占用明确区域，并加入几何断言。
- 大字体测试推动了页码和播放栏的紧凑呈现；下载开始/取消/打开按钮固定在底部，正文可滚动。普通字号、深色及最大辅助字号均纳入截图验收。
- iOS 26 的删除确认菜单仅显示删除动作、取消依靠点外部；改用含明确取消按钮的弹窗。
- 保留正文初次挂载时的断点滚动，新增第 18 段冷打开可见且保持暂停的 UI 验收。

## 真机最终验收仍待进行

模拟器验收不代替真实 Kindle 会话及严格飞行模式验收。下一轮使用手机完成：同书同版式整本采集计时与源页比对、下载取消及恢复、严格断网冷启动首次 OCR/TTS、跨章实听与高亮、锁屏/后台朗读及返回断点。真实下载是否达到 30–60 秒尚未重新测量，本轮不宣称提速达标。

当前下载仍要求 App 保持前台；锁屏或切到其他 App 会暂停并保留进度。已经保存的书走本机阅读与系统朗读路径，两种状态的后台行为不能混为一谈。
